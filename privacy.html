プライバシーポリシー（yt-concept-lab）

最終更新日: 2026年10月5日

1. このツールについて

yt-concept-lab（以下「本ツール」）は、運営者が自分の YouTube チャンネルに、自分で制作した動画を投稿・予約公開し、サムネイルやチャンネルの説明文・バナーを設定するためだけに使う個人用のツールです。運営者以外の方には提供していません。

2. YouTube API Services の利用

本ツールは YouTube API Services を利用しています。本ツールの利用には、YouTube 利用規約が適用されます。Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。

3. 取得する情報と使い方

  • 運営者が Google アカウントで許可したときに発行される認証情報（アクセストークン・更新トークン）を、運営者の手元のコンピュータにだけ保存します。
  • 認証したチャンネルの ID・名前・ハンドルを、投稿先の取り違えを防ぐ確認のためにだけ読み取ります。
  • 投稿した動画の ID と公開状態を、投稿の記録としてのみ手元に保存します。
  • 運営者以外の方の個人情報、視聴者の情報、コメントなどは取得しません。
  • 取得した情報を第三者に提供・販売することはありません。

4. 保存と削除

認証情報と記録は運営者の手元のコンピュータにだけ保存し、外部のサーバーには送りません。運営者は、手元のファイルを消すことでいつでも削除できます。また、Google アカウントの「サードパーティによるアクセス」から、本ツールへのアクセス許可をいつでも取り消せます。

5. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。

Privacy Policy (English summary)

yt-concept-lab is a personal tool used only by its operator to upload and schedule the operator's own videos, and to set thumbnails, channel descriptions and banners, on the operator's own YouTube channels. It uses YouTube API Services; by using it, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy. OAuth tokens, the authorized channel's ID/title/handle (used only to verify the upload destination), and uploaded video IDs are stored only on the operator's own computer, are never shared or sold, and can be deleted at any time; access can be revoked via Google security settings. The tool collects no data about other users or viewers.
