yt-concept-lab

yt-concept-lab は、運営者が自分の YouTube チャンネル（「宙のなぜ」「統計のからくり」など）に、自分で制作した解説動画を投稿・予約公開するためだけに使う、個人用のツールです。

このツールは YouTube API Services を使っています。運営者以外の方が利用することはなく、運営者以外の方の情報を集めることもありません。

  • プライバシーポリシー
  • 宙のなぜ（YouTube）
  • 統計のからくり（YouTube）

yt-concept-lab is a personal tool used only by its operator to upload and schedule the operator's own videos to the operator's own YouTube channels. It uses YouTube API Services. It is not offered to other users and does not collect data about other people.
